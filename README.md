# Line Chart

Интерактивное приложение для визуализации результатов A/B‑теста: конверсия нескольких вариаций отображается в виде линейных/площадных графиков с возможностью фильтрации, масштабирования и экспорта.

[https://kulob.github.io/line-chart/]

## Что реализовано
- **Загрузка и подготовка данных.** Файл `data.json` отдается как статический ресурс (`/data.json`). Данные агрегируются по дням или неделям и преобразуются в показатели конверсии для каждого варианта эксперимента.
- **Компонентная архитектура.** Отдельные модули для графика (`LineChart`), панели управления (`Controls`), выбора вариаций (`VariationSelector`) и подсказок (`CustomTooltip`). Стили изолированы с помощью CSS Modules + Sass.
- **Состояние и тема.** Zentralized store на базе `zustand` управляет светлой/темной темой, состояние сохраняется в `localStorage`.
- **Графика на Recharts.** Используются `LineChart`, `AreaChart`, `ResponsiveContainer`, кастомные tooltip'ы и цвета вариаций.
- **Сборка и Dev‑сервер.** Проект собран на Vite + React 19 + TypeScript; доступны скрипты `dev`, `build`, `preview`, `lint`.

## Как запустить локально
1. **Требования.** Node.js ≥ 20 и npm или Yarn.
2. **Установка.**
   ```sh
   git clone <repo-url>
   cd line-chart
   yarn install
   ```
3. **Данные.** По умолчанию используется `data.json` в корне. Если нужно заменить датасет:
   - обновите файл `data.json` или положите свой в `public/data.json`;
   - структура должна соответствовать интерфейсам `ChartData`/`DataPoint`.
4. **Старт dev‑сервера.**
   ```sh
   yarn dev
   ```
   Откройте `http://localhost:5173`, чтобы увидеть график.
5. **Продакшн‑сборка и предпросмотр.**
   ```sh
   yarn build
   yarn preview
   ```
6. **Линтинг.**
   ```sh
   yarn lint
   ```

## Добавленные фичи
- **Выбор вариаций.** Можно включать/выключать любую комбинацию вариантов эксперимента; цвета и подписи синхронизированы в тултипах и легенде.
- **Диапазон времени.** Переключение `Day/Week` пересчитывает данные через `aggregateByWeek`, позволяя анализировать тренды без шумов.
- **Тип графика.** Режимы `Line`, `Smooth`, `Area` с разными типами интерполяции и заливкой.
- **Зум и сброс.** Кнопки `ZoomIn/ZoomOut` ограничивают домен оси X на центральном сегменте и возвращают полный диапазон.
- **Экспорт в PNG.** Через `html2canvas` можно выгрузить текущий вид графика (включая тему и выбранные вариации) одним кликом.
- **Темная/светлая тема.** Тумблер в панели управления, состояние хранится между сессиями.
- **Расширенный tooltip.** Кастомная подсказка показывает значения всех активных вариаций, сортирует их по лучшему результату и выделяет лидера эмодзи-трофеем.
- **Адаптивность.** Контейнеры на `ResponsiveContainer` подстраиваются под ширину экрана, управление остается кликабельным на планшетах и десктопах.
